# Lab ID conventions

_Fictional demo data generated for Exin Lab Search. Not real experimental results._

Every record must use these IDs exactly, so files can be linked.

| Prefix | Meaning | Example |
|---|---|---|
| `M-###` | Mouse | M-042 |
| `V-###` | Virus batch (see virus_batches.csv) | V-017 |
| `EXP-###` | Experiment | EXP-007 |
| `C-##` | Cohort (a group of mice in one experiment) | C-07 |
